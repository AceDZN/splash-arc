# Splash Arc — קשת המים

A 3D summer-camp water-balloon war for Hebrew-speaking grade-9 students. You don't pull back and guess: you **drag the vertex** of the arc, the live equation `y = a(x − p)² + k` updates, and the balloon flies exactly along that parabola into wobbling cardboard forts. Workbook grade 9, chapter 4 (הפונקציה הריבועית); see [CURRICULUM.md](CURRICULUM.md).

TypeScript + Vite + Three.js, Rapier physics for the forts (visual consequence only; the math decides every hit), rigged Tripo campers and Tripo set pieces, synthesized sound. No backend, no accounts, no analytics, nothing fetched at runtime.

## Run

```bash
npm install
npm run dev        # http://localhost:5212
npm test           # rules, levels, solver and state-machine tests
npm run build      # static build in dist/ (relative base, works offline)
npm run preview    # http://localhost:4212
```

URL options: `?level=N` jumps straight to level N (1–7); `?autopause=0` keeps the game running in a background tab (for automated runs).

## Controls

- **Drag** anywhere on the field to place the glowing vertex (snaps to 0.5 m; **צעד עדין** switches to 0.1 m).
- **k / p buttons** (− / +) nudge the vertex height and position: a second representation of the same curve.
- **שגר!** (or Space / Enter) fires. On the return-fire level the same button means **מוכן!** and you drag the bucket instead.
- Keyboard: arrows move the vertex (or the bucket), `F` fine step, `H` hint, `P`/`Esc` pause, `R` restart, `M` mute.
- Pause menu: restart, level select, mute, reduced motion.

## What's implemented

- Seven authored levels (over the wall, piñata, lifeguard tower, return fire, drifting raft, double lanterns, night-raid transfer level) plus endless **challenge raids** generated by a solver that guarantees a window of valid `k` (and that "always k = 8" fails most of them).
- Pure rules in `src/math/` and `src/game/` (no Three.js): exact parabola tracing against walls, nets, branches, bunting, rings and targets; raft drift as a horizontal shift; rival volleys in vertex and factored form.
- Help that fades: dotted preview to the vertex → short stub → none; landing marker and zeros chip only early; no hints or grid numbers on the transfer level.
- Consequences instead of "wrong answer": wall splats with the height `y(x)` shown, the net or branch catches the balloon, `a ≥ 0` flies off to space, rival balloons soak your camper. A short worked explanation follows every miss; the real flight path stays on screen.
- Juice: splash particles, wet spots, pop-up words, camera shake, toppling cardboard and pillows, Tripo campers (idle/cheer clips plus procedural throw/soaked accents), synthesized sound after the first gesture.
- Hebrew RTL HUD with every formula in LTR isolates; bundled Rubik font; desktop and phone (portrait and landscape) layouts.
- `window.render_game_to_text()` and deterministic `window.advanceTime(ms)` for testing; anonymous learning events in `localStorage` only.

Planned but not built: a dedicated stretch (`a`) control, more return-fire variety inside the shooting levels, a teacher view of the learning log.

## Deploy to Vercel

The build is fully static. In Vercel: framework preset **Vite**, build command `npm run build`, output directory `dist`. Or from the CLI: `npx vercel --prod` in this folder. Not deployed yet.
